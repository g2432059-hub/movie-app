# 改善の計画(devだけで試す。結果を見る前に固定)

- 決めた日時: 2026-10-30(test 1回目の実行後。testは残り1回。改善の評価にはtestを使わない)
- 課題: MF/NCFのRMSEが平均評価より悪い。高評価の入力で予測が5に偏る(clip前で最大5.54)
- 仮説: fold-inのl2(初期値への引き戻し)を強めると、5本の入力への過剰なフィットが減り、RMSEが改善する。効くかは未検証
- 条件: l2 ∈ {0.01(現在), 0.03, 0.1, 0.3, 1.0}。steps=50、lr=0.05は固定。MFとNCF(λ=0, 0.25)をdevで評価
- 採用基準:
  1. NCFのdev RMSE(pooled)が最小のl2を選ぶ
  2. ただし、NCFのP@10(top25, λ=0)が現在値(0.1781)より0.005以上下がるl2は採用しない
  3. 現在値(0.01)に対するRMSEの改善が0.01未満なら「効果なし」とし、現在値のままにする
- 注意: 閾値は経験的に決めた値で、根拠は強くない
- 採用した場合: recommender.py の既定のl2を変更し、app.py も同じ設定にする。test 2回目(11/1)で、変更後の結果を報告する
